LPD Feature 17 — Shopify Custom Feature Section

A fully customizable and responsive feature + media section for Shopify, supporting dynamic headings, descriptions, feature list items, icons, and image/video media. Built using Liquid, HTML, CSS, and jQuery, this component is perfect for landing pages, product highlights, and brand storytelling sections.

🚀 Key Features
🎨 1. Dynamic Typography & Fonts

Google Fonts integration per block

Custom font toggle

Heading & description font selection

Desktop + mobile font sizes

📝 2. Flexible Content Blocks

Includes 3 block types:

Heading

Description

Featured Items (icon + title + description)

Each block has full controls for:

Text

Font family

Text color

Font size

Custom checkboxes for using custom typography

🏞️ 3. Media Support (Image or Video)

Choose your media type:

Image

Video (autoplay, muted, loop)

Supports separate media for:

Desktop

Mobile

📱 4. Responsive Layout

Dynamic media position (left/right on desktop, top/bottom on mobile)

Adjustable section gaps

Mobile/desktop padding

Mobile-specific media height and object-fit

🧱 5. Customizable Feature List

Each feature item includes:

Icon container size

Icon image size

Icon background color

Custom or fallback icon

Feature heading with font control

Feature description with font control

Automatically detects and styles the last feature in the list.

🎛️ 6. Layout Customization

From the Shopify theme editor, you can control:

Padding (desktop & mobile)

Media width

Media height

Border style (solid, dashed, dotted, double)

Border color & thickness

Image rounding

🧩 Tech Stack

Shopify Liquid

HTML5

CSS3

jQuery

Google Fonts API

📦 Installation

Go to Shopify Admin → Online Store → Edit Code

Open the Sections folder

Click Add New Section

Name it: lpd-feature-17.liquid

Paste the full code

Save and add the section through the Shopify Theme Customizer
